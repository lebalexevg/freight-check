# «Рейс-Проверка»

Автономная десктоп-утилита для локальной автоматической кросс-валидации между входящей заявкой на перевозку и черновиком электронной транспортной накладной (ЭТрН) до выпуска машины в рейс и передачи документов в ГИС ЭПД.

---

## Ключевые особенности и архитектурные принципы

- **100% Локальная обработка:** Все документы, текст и персональные данные обрабатываются строго локально в оперативной памяти. Никаких отправок документов или фрагментов текста во внешнюю сеть.
- **Stateless In-Memory:** Отсутствие локальных баз данных. Сессионные данные гарантированно уничтожаются при завершении проверки или закрытии приложения.
- **Легковесность и работа на CPU:** Потолок потребления ОЗУ процессом — **до 1.5 ГБ**. Все алгоритмы и нейросетевое распознавание оптимизированы для обычных офисных CPU.
- **Поддержка любых форматов:** Прием заявок и накладных в виде PDF, Excel, CSV, Word, растровых изображений и регламентированных XML-титулов ЭТрН ФНС.
- **Умное сопоставление реквизитов:** Посимвольная сверка госномеров с коррекцией ошибок по ГОСТ-маске, нормализация веса и контроль перегруза, раздельная проверка адресов (строгий контроль номеров домов и нечеткое сравнение улиц), контроль достоверности OCR.
- **Отзывчивый UI:** Графический интерфейс на PySide6.

## Стек технологий

- **Среда выполнения:** Python 3.13
- **Менеджер пакетов:** [`uv`](https://github.com/astral-sh/uv)
- **Пользовательский интерфейс:** `PySide6`
- **Парсеры структурированных данных:** `openpyxl`, `xlrd`, `python-docx`, `pdfplumber`, `xml.etree.ElementTree`
- **OCR и компьютерное зрение:** `pypdfium2`, `opencv-python-headless`, `Pillow`, `rapidocr-onnxruntime`
- **Нечеткое сопоставление:** `rapidfuzz`
- **Контроль качества:** `ruff`, `basedpyright`, `pytest`, `pre-commit`
- **Дистрибуция:** `PyInstaller`, `Inno Setup`

## Быстрый старт

### Требования
* Установленный **Python 3.13**
* Менеджер пакетов [**`uv`**](https://github.com/astral-sh/uv)

### Установка и запуск

```bash
# 1. Клонирование репозитория
git clone <repo-url>
cd freight-check

# 2. Установка зависимостей и синхронизация виртуального окружения
uv sync

# 3. Активация pre-commit проверок
uv run pre-commit install

# 4. Запуск утилиты в режиме разработки
uv run freight-check
```

## Структура репозитория

```text
freight-check/
├── assets/
│   ├── models/                # Локальные веса ONNX (RapidOCR)
│   └── styles/                # Таблицы стилей интерфейса (QSS)
├── docs/                      # База знаний и спецификации проекта
│   ├── README.md              # Навигационный указатель документации
│   ├── product.md             # Продуктовая спецификация
│   ├── architecture.md        # Архитектурная и техническая спецификация
│   └── contributing.md        # Руководство разработчика и Git-регламент
├── src/
│   └── freight_check/
│       ├── contracts.py       # Единый источник контрактов данных (Dataclasses)
│       ├── ui/                # PySide6 виджеты, Drag-and-Drop, QThread worker
│       ├── parsers/           # Прямое чтение файлов и конвейер OCR
│       └── core/              # Семантика, нормализация и сопоставление
├── tests/                     # Модульные, интеграционные и системные тесты
├── .pre-commit-config.yaml    # Автоматизация проверок перед коммитом
├── pyproject.toml             # Конфигурация uv, ruff, basedpyright, pytest
├── AGENTS.md                  # Инструкции и правила для ИИ-агентов
└── README.md                  # Главная страница проекта
```
